**Détails techniques**
- Fonction `calculer_totaux(lignes, mode_livraison)` : sous-total, livraison, TVA incluse, total
- Taux de TVA dans la configuration (8.1 %), jamais écrit en dur
- Montants en centimes entiers, jamais de `float`
